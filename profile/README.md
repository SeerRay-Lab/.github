# SeerRay-Lab

Frontier research on Visual Intelligence: see further, build together.

## Research

We study how AI systems perceive, understand, and interact with the visual world. Our research spans multimodal reasoning, document understanding, and GUI agents, with an emphasis on learning and evaluation in real-world settings.

## Projects

### Xiaomi-GUI-0

An end-to-end multimodal GUI agent for real mobile environments, trained and evaluated in a real-device closed loop. It combines interface understanding, multi-step planning, and error recovery. The repository includes the RealMobile benchmark, evaluation tools, and a desktop client for interacting with real phones.

[Code](https://github.com/SeerRay-Lab/Xiaomi-GUI-0) · [Technical Report](https://arxiv.org/abs/2606.31410) · [Project Page](https://seerray-lab.github.io/Xiaomi-GUI-0/)

### Xiaomi-OCR-0

A unified 0.8B vision-language model for document parsing and OCR-centric understanding. It converts document images into structured Markdown with tables and formulas, extracts key information, and answers questions about document content. The repository provides inference pipelines, a browser demo, and tools for agent integration.

[Code](https://github.com/SeerRay-Lab/Xiaomi-OCR-0) · [Model](https://huggingface.co/SeerRay-Lab/Xiaomi-OCR-0) · [Technical Report](https://arxiv.org/abs/2609.36136)
