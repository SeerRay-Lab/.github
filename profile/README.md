# SeerRay-Lab

## Research

We are the Visual Understanding Group within Xiaomi's Large Language Model (LLM) Applications Team ([@XiaoMi](https://github.com/XiaoMi) · [@xiaomi-research](https://github.com/xiaomi-research)).

We study how AI systems perceive, understand, and interact with the visual world. Our research spans multimodal reasoning, document understanding, and GUI agents, with an emphasis on learning and evaluation in real-world settings.

## Projects

| Project | Focus | Resources |
| --- | --- | --- |
| **Xiaomi-GUI** | Multimodal GUI agents for real mobile environments, combining interface understanding, multi-step planning, and error recovery. Includes the RealMobile benchmark and evaluation tools. | [Code](https://github.com/SeerRay-Lab/Xiaomi-GUI-0) · [Report](https://arxiv.org/abs/2606.31410) · [Project Page](https://seerray-lab.github.io/Xiaomi-GUI-0/) |
| **Xiaomi-OCR** | Document parsing and OCR-centric understanding: structured Markdown with tables and formulas, key information extraction, and visual question answering. Includes inference pipelines and tools for agent integration. | [Code](https://github.com/SeerRay-Lab/Xiaomi-OCR-0) · [Model](https://huggingface.co/SeerRay-Lab/Xiaomi-OCR-0) · [Report](https://arxiv.org/abs/2609.36136) |
| **Xiaomi-Lens** | Fine-grained region understanding and grounded chain-of-thought reasoning with visual latents, spanning referring and reasoning segmentation, multi-instance grounding, and visual perception. Includes the LensBench segmentation benchmark. | [Code](https://github.com/SeerRay-Lab/Xiaomi-Lens-0) · [Model](https://huggingface.co/SeerRay-Lab/Xiaomi-Lens-0) · [Report](https://arxiv.org/abs/2610.23279) · [Project Page](https://seerray-lab.github.io/Xiaomi-Lens-0/) · [LensBench](https://huggingface.co/datasets/SeerRay-Lab/LensBench) |
